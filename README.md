# Замер скорости скачивания

Консольный скрипт последовательно скачивает данные по указанному адресу 10 раз, каждый раз дожидаясь полного ответа. В конце он печатает среднее время запроса, общий объём и среднюю скорость скачивания.

## Требования

- Python версии 3.9 или новее
- Дополнительные пакеты не нужны

## Запуск

В каталоге проекта выполните:

```bash
python download_speed.py "https://cdn.steamstatic.com/apps/dota2/videos/dota_react/heroes/renders/pudge.png"
```

В Windows можно использовать команду `py`:

```powershell
py download_speed.py "https://cdn.steamstatic.com/apps/dota2/videos/dota_react/heroes/renders/pudge.png"
```

Для отдельных сетевых операций задан тайм-аут 30 секунд; полная загрузка может занять больше. Скрипт поддерживает адреса HTTP и HTTPS. При сетевой или HTTP-ошибке он выведет сообщение и завершится с кодом `1`.

## Единицы измерения

- Время указано в секундах (`с`).
- Объём указан в десятичных мегабайтах (`MB`), где `1 MB = 1 000 000` байт. В итоговой строке также показано точное количество байт.
- Скорость указана в `MB/s` и рассчитывается как общий объём скачанных данных, делённый на суммарное время 10 запросов.
